[TITLE] (Maximum 45 characters)
ScreenShot Turbo

[SUMMARY] (Maximum 132 characters)
Fast and professional screenshot capture, crop, annotation editor, and export tool for Chrome and Edge.

[CATEGORY]
Productivity (or Photos)

[DESCRIPTION]
Capture, crop, annotate, and export high-quality screenshots in seconds! ScreenShot Turbo is a lightweight, all-in-one browser extension designed for developers, designers, content creators, and everyday professionals who need reliable screen captures without bloat or privacy risks.

Whether you need a quick visible snapshot, an entire scrolling webpage, or a pixel-perfect aspect ratio crop, ScreenShot Turbo provides an intuitive experience with a powerful built-in editor.

KEY FEATURES:

* Multiple Capture Modes:
  - Visible Window: Instant capture of your current viewport with a single click or shortcut.
  - Full Page Capture: Smart automated scrolling engine that stitches long articles and dashboards seamlessly, automatically hiding duplicate fixed headers.
  - Interactive Free Selection: On-page selection layer with 8-point resize handles, live pixel dimensions, direct copying, and quick saving.
  - Preset Aspect Ratios: Mathematical locking for 1:1 (Square), 3:2 (Photo), 4:3 (Standard Monitor), 5:4 (Frame), and 16:9 (Widescreen), with instant toggle between Landscape and Portrait orientations.

* Built-in Annotation & Drawing Editor:
  - Automatic preview editor window opens right after each capture.
  - Vector & Shape Tools: Draw straight lines, arrows, rectangles, circles, and multi-point continuous polylines.
  - Text & Freehand Brush: Add explanatory text with custom colors/backgrounds or draw freely with a customizable brush.
  - Non-destructive Canvas Cropping: Adjust the final crop area anytime before exporting.
  - Zoom & Navigation: Zoom in/out, fit to screen, or view at 100% actual resolution.
  - Instant Clipboard Copy: Copy formatted PNG screenshots directly to your clipboard (Ctrl+V) ready to paste into Slack, Discord, WhatsApp, Notion, or email.

* Flexible Multi-Format Export:
  - PNG: Crystal-clear lossless quality supporting full transparency.
  - JPG: Adjustable compression quality (10% to 100%) and customizable solid background colors.
  - WebP: Modern ultra-compact image format for web publishing and reduced disk usage.
  - Directory Memory: Remembers your last saved folder across sessions, saving you time.

* Native Global Shortcuts:
  - Alt + Shift + V : Capture Visible Window
  - Alt + Shift + F : Capture Full Page
  - Alt + Shift + S : Start Free Selection
  - Alt + Shift + 1 to 4 : Quick Aspect Ratio Selections (1:1, 3:2, 4:3, 5:4)
  - Esc : Cancel selection or dismiss overlay

* 100% Privacy Focused & Local Processing:
  - All image rendering, canvas cropping, and conversions are executed purely inside your browser.
  - Zero external servers. Zero tracking. Zero data collection.

[JUSTIFICATION OF PERMISSIONS — REQUIRED IN ENGLISH FOR REVIEWERS]

* activeTab:
  Required to capture the visible contents of the currently active browser tab when the user explicitly triggers a capture command or action, and to display the interactive crop overlay directly on that page.

* tabs:
  Used exclusively to query the active tab's URL and title for naming captured screenshots, and to open the local preview editor tab (editor.html) or settings tab upon user request.

* storage:
  Used to store the user's local capture presets, default image formats, compression levels, and UI options via chrome.storage.local. No data leaves the user's machine.

* unlimitedStorage:
  Required to temporarily cache high-resolution, full-page stitched canvas screenshots in memory and local storage so they can be smoothly handed over to the built-in editor without crashing browser memory limits.

* downloads:
  Required to export and save the final screenshot files (PNG, JPG, or WebP) directly into the user's chosen local downloads directory when the user clicks the save button.

* scripting:
  Required to execute the full-page scrolling scanner script and inject the interactive crop overlay elements into the active webpage only during user-requested screen capture sessions.
